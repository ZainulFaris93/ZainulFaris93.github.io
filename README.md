# zainulfaris93.github.io

Personal portfolio of **Zainul Faris V K**, Python full stack developer (Django).
Live at **https://zainulfaris93.github.io**

## Updating the site (no coding needed)

| I want to… | Do this on GitHub |
|---|---|
| Replace my résumé | Upload a new PDF named `resume.pdf` to the repo root (it replaces the old one). |
| Send a tailored résumé | Upload e.g. `resume-acme.pdf`, then share `https://zainulfaris93.github.io/?cv=acme`. |
| Change email / LinkedIn / GitHub links | Edit `assets/settings.js`. |
| Show a new project | Make the repo public. It appears automatically under "More on GitHub". Set the repo's **Website** field to show a "Live" button. |
| Hide a repo from that list | Add its name to `hideRepos` in `assets/settings.js`. |

Changes go live about a minute after you commit.

## Structure

```
index.html                  home page
projects/*.html             case studies
assets/site.css             shared styles (dark + light themes)
assets/site.js              theme toggle, menu, résumé + live-demo links
assets/settings.js          your links and settings
assets/hms/                 hospital app screenshots
resume.pdf                  the résumé visitors download
```
