Smart Dog Repellent System

A computer-vision system that watches a camera feed, detects dogs in real time with YOLOv8, and triggers a hardware response over a serial link, with nobody needing to watch.

TypeAI + hardware project
ModelYOLOv8 object detection
StackPython · OpenCV · Serial
RunsReal time

01The problem

Stray dogs around homes and public spaces are a common safety concern. Someone watching a camera all day doesn't scale. The idea was to let a model do the watching and respond automatically.

02How it works

03What I built

  • Real-time detection of dogs in the video stream using YOLOv8
  • Serial communication between the Python detection program and the hardware, so a detection becomes a physical response
  • Applied object detection and real-time computer vision to a project that has to work in the real world, not just on a test dataset
