Real-Time Landslide Detection & Alerting

An environmental monitoring system that reads sensor data from the field, uses machine learning to spot landslide risk, and raises alerts through a web platform. I led the machine learning work.

01The problem

Landslides strike hilly regions with little warning, and manual monitoring can't watch every slope all the time. The goal was a system that watches continuously and warns people early.
